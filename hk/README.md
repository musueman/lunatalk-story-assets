# hk

Luna 검열판 WebP 자산입니다. 원본 PNG는 이 저장소 밖에 보존합니다.

## 경로

`hk/<subject-code>/<two-digit-number>.webp`

- `hk`는 **홍콩 가는 건 참을 수 없잖아?**의 약자입니다.
- `subject-code`는 의미를 담지 않는 소문자 알파벳 한 글자입니다. 캐릭터·도시·상황의 이름은 경로에 쓰지 않으며, 실제 대상을 찾는 매핑은 별도로 관리합니다.
- 원본의 두 자리 번호를 그대로 유지합니다. 예: `hk/a/01.webp`입니다.
- 인물 에셋은 위의 코드·번호 체계를 유지합니다.

## 상황 이미지

`hk/scenes/<scene-key>.webp`

- 시작 장면처럼 인물이 아닌 상황을 설명해야 하는 그림은 `scenes` 폴더에 넣습니다.
- `scene-key`는 영문 소문자와 하이픈으로 구성하며, 장면의 쓰임을 바로 알 수 있게 작성합니다.
- 원본 PNG는 이 저장소 밖에 보존하고, 이 폴더에는 검열판 WebP만 둡니다.
- `-v2` 시작 장면은 캐스팅·시점·장소를 실제 시작 메시지와 대조해 재제작한 교체본입니다. LunaTalk 시작 메시지는 레거시 파일이 아니라 해당 `-v2` 파일을 사용합니다.
- `was-that-real-interview-room-v3.webp`는 `-v2` 면담 장면에서 홍서연의 헤어 색이 잘못 드리프트한 것을 정정한 캐스팅 고정본입니다. 면담 시작 메시지는 이 파일을 우선 사용합니다.

`map.json`은 공개 파일 수와 경로 형식만 기록합니다. 코드의 실제 대상 매핑은 포함하지 않습니다.
