# Hero Harem uncensored WebP key map

## File key format

`{character}_{situation}_{number}.webp`

Directory layout: `{character}/{situation}/{character}_{situation}_{number}.webp`

- `number`: three-digit sequence (`001`–`017`), ordered by the original filename within each character/situation folder.
- The original PNG files and their detailed semantic filenames remain unchanged in the canonical source tree.
